# Scovi
Scovi helps you visualize code coverage reports generated by Go tools in a clear and interactive way. It supports multiple output formats and provides filtering options to focus on specific packages or files.

### Features

- Visualizes Go coverage profiles in the browser
- Supports filtering by package, file, or function
- Command-line flags for customization

### Usage Flags

- `-file`: Path to the Go coverage profile file (required)

## Installation

To install Scovi, use `go get`:

```bash
go get github.com/zikrullah79/scovi
```
